# IgniteGym

**IgniteGym** é uma aplicação para gerenciamento de academias, permitindo que os usuários se registrem, acessem informações sobre as academias e façam check-ins. O objetivo do projeto é fornecer uma plataforma intuitiva para interagir com os dados das academias de maneira simples e eficaz.

---

## **Tecnologias Utilizadas**

- **React Native**: Framework para construção de aplicativos móveis para iOS e Android com JavaScript e React.
  
- **TypeScript**: Superset de JavaScript que traz tipagem estática, melhorando a robustez e manutenção do código.

- **React Navigation**: Biblioteca para navegação entre telas no React Native, permitindo a criação de navegação fluida no aplicativo.

- **Styled-components**: Utilizado para estilizar os componentes de forma modular, melhorando a organização do código e a reutilização de estilos.

- **Redux**: Utilizado para o gerenciamento de estado global da aplicação, facilitando a manutenção e rastreamento dos dados.

---

## **Funcionalidades**

- ✅ Cadastro e autenticação de usuários.
- ✅ Visualização das academias disponíveis.
- ✅ Realização de check-ins em academias.
- ✅ Histórico de check-ins do usuário.
- ✅ Perfil do usuário.
